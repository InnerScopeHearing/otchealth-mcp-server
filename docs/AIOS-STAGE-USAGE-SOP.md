# Content-free provider usage receipts: operator SOP

This source change adds one structured `provider_usage_receipt` per successful OpenAI response. Receipts carry only the fixed provider, closed call kind/stage, validated correlation and release identifiers, actual returned model when present, raw returned token counts, and `usage_state` (`reported`, `missing`, or `invalid`). A real zero remains `reported` zero; malformed or incomplete counters are `invalid`; absent usage is `missing`.

Estimated USD is distinct from observed usage and from provider billing. It is emitted only for complete valid counters and has `estimate=true`, `price_table_version=2026-09-03`, `unknown_model_price`, and an explicit `estimate_model_source`. When the response omits its model, a selected/requested model can be used only as an explicitly labeled fallback. Existing `otc.fleet.openai.*` metrics retain their existing names and tags for dashboard compatibility; do not infer stage attribution from those aggregate counters.

Receipts contain no prompts, answers, queries, passages, rooms, caller identity, credentials, arbitrary response properties, or identifier metric tags. The `unknown` stage means no foreground deep-retrieval stage was bound. Async-local stage tags describe execution context, not business intent. Background/shadow work inheriting request context must be labeled and excluded from foreground comparisons until separately understood. For a single logical multi-room request, query the one scoped owner record and batch read once; do not fan out duplicate owner reads. Stage receipts are instrumentation, not cost reduction evidence. Savings claims require a fixed quality holdout and provider billing reconciliation.

Receipts cover successful provider responses. Failed or retried calls without returned usage are unavailable, not proven free. The explicit shadow stage is excluded from foreground stage totals. Do not count unknown_model_price estimates as known cost; report unpriced calls separately. This gateway receipt is distinct from the toolkit's returned-only usage receipts and existing aggregate fleet metrics.
